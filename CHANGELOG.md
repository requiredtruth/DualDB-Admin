# Changelog

## 0.1.0 - 2026-08-24

- Added the same `main.php` entry point for responsive web administration and structured CLI commands.
- Added SQLite/MySQL discovery, schema inspection, bounded browsing, CRUD, SQL, full export, CSV/JSON import, automatic collision numbering, table groups, and bidirectional table transfer.
- Added a native dependency-free Android WebView shell targeting SDK 35 down to SDK 19, without Cordova.
- Added Gradle and raw Android SDK APK build paths, PHP integration tests, static contract tests, CI, and documentation.
