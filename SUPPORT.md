# Support development

Donations increase the time available for production. A sender may open a funded-direction issue with the asset, exact network, public transaction hash, and a specific compatible work area. The first valid public issue claiming an unclaimed confirmed hash receives request attribution for that transaction; this is not cryptographic proof of wallet ownership.

A donation does not purchase support, ownership, investment returns, a deadline, preferential treatment, or guaranteed implementation. Confirm the asset, destination, and network before sending; transactions are irreversible.
